## 構築

### Electron Forge でプロジェクトの土台を作成する

- Vite + TypeScript のプロジェクトを作成する
- 参考: [https://www.electronforge.io/templates/vite-+-typescript]
  - ※上記のページと下記のコマンドはちょっと違います。

```shell
PROJECT_NAME="hoge"
npx create-electron-app@latest $PROJECT_NAME --template vite --typescript
```

### React を導入する

- 参考1: [https://www.electronforge.io/guides/framework-integration/react-with-typescript]
- 参考2: [https://react.dev/learn/add-react-to-an-existing-project]

React のパッケージ類をインストール

```shell
npm install --save react react-dom
npm install --save-dev @types/react @types/react-dom
```

`tsconfig.json` に以下の定義を追加する

```json comments
{
  "compilerOptions": {
    "jsx": "react-jsx",
  }
}
```
